Privacy Policy

Last updated: 13 November 2026

Whystory uses a private internal tool to upload and schedule videos to its own YouTube channel and to read that channel's analytics, via the YouTube Data API and YouTube Analytics API.

  • The tool accesses only the Whystory channel's own data.
  • No data from other users is collected, stored, sold or shared.
  • OAuth credentials are stored privately and used only to manage the Whystory channel.
  • Access can be revoked at any time at https://myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: via the Whystory YouTube channel, https://www.youtube.com/@whystory-en
